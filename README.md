# D.F. Marketing Digital — Site

Arquivos:
- `index.html` — site completo, responsivo e sem dependências locais.
- `df-logo.jpg` — logo fornecida para a D.F.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `SEUUSUARIO.github.io`.
2. Envie `index.html` e `df-logo.jpg` para a raiz do repositório.
3. Vá em Settings → Pages.
4. Em Build and deployment, escolha `Deploy from a branch`.
5. Branch: `main`; pasta: `/ (root)`.
6. Salve e aguarde a publicação.
7. Acesse `https://SEUUSUARIO.github.io`.
